# CGT 215 Lab 05 - VFX BLITZ Cypher

This project translates uppercase and lowercase letters with the Lab 05 cipher table. Non-letter characters are preserved, including spaces, numbers, punctuation, and symbols.

## Build

Open `CGT215_Lab5.vcxproj` in Visual Studio, or compile the source with a C++17 compiler:

```text
g++ -std=c++17 CGT-215-Lab-05-myasutak.cpp -o lab05
```

## Example

Input:

```text
!#@APZapz
```

Output:

```text
!#@VOEvoe
```
