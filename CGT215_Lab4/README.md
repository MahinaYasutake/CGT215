# CGT 215 Lab 04 - Flow Control

This program practices branches, loops, input validation, and functions by allowing the user to calculate:

- A factorial
- An arithmetic series
- A geometric series

The program displays the terms used in each calculation and allows the user to run another operation.

## Build

Compile `CGT-215-Lab-04-myasutak.cpp` with a C++ compiler, for example:

```text
g++ -std=c++17 CGT-215-Lab-04-myasutak.cpp -o lab04
```
